# Project Library logo assets

Generated with the built-in `image_gen` tool. All three PNGs are 1254 by 1254 pixels.

| File | Background |

The mark combines stacked prompt cards with a terminal chevron and cursor. The violet/cyan direction follows the existing terminal interface.

## Generation prompts

### Transparent master

Use case: logo-brand. Asset type: square project logo for plib, an open-source command-line prompt library. Create ONE original, finished logo mark on a genuinely transparent alpha background, square 1024 by 1024 canvas. Concept: a compact stack of two rounded prompt cards arranged like the pages of a small upright book or library; the front face integrates a clear terminal chevron and short cursor bar, >_, as part of the emblem. Unify the page silhouette and terminal glyph into one distinctive balanced geometric mark, rather than a generic terminal window. Style: flat, vector-like, exceptionally crisp, bold simple silhouette, softly rounded corners, strong negative space, legible at small sizes. Color direction: violet and cyan already used by the plib terminal interface; make the emblem high contrast and self-contained so it works on light and dark backgrounds. Composition: one centered emblem occupying about 70 percent of both canvas dimensions, generous equal transparent margins, straight-on view. No wordmark, no explanatory text, no extra decorative elements, no enclosing app tile, no border, no shadows, no glows, no gradients, no texture, no mockup. Actual transparency, never a painted checkerboard.
